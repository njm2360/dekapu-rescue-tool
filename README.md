# でかプ データ復旧ツール

VRChatのログに残っているクラウドセーブURLを拾い出して、任意の時点のセーブを送信するツールです。
ロールバックが起こってもログさえ残っていれば任意の時点の値でセーブを巻き戻すことが可能です。

## 使い方

1. [Releases](https://github.com/njm2360/dekapu-rescue-tool/releases/latest) から `DekapuRescueTool.exe` をダウンロードして実行します。
2. 起動時に `%USERPROFILE%\AppData\LocalLow\VRChat\VRChat` を自動で読み込みます。別の場所にログを退避している場合は「参照」で選び直してください。
3. ユーザーと日付を選ぶと、その日の総獲得の推移がグラフとして表示されます。
4. 戻したい時点を選びます。グラフ上の点を直接クリックするか、矢印ボタンや左右キーでも選択可能です。
5. 「保存」を押して、確認ダイアログでOKをクリックするとクラウドセーブサーバーに送信されます。
6. ワールド内のクラウドロード機能でデータをロードします。読み込み前に値が正しいことを確認してください。
7. ロードした後はメダルを1枚以上投入してからワールドを退出してください。(ロード値をセーブさせるため)

グラフはホイールでズーム、左ドラッグで範囲ズーム、中ドラッグでパン操作ができます。
